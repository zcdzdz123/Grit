# 사진 100장 이름 바꾸기, 탐색기에서 하나씩 하지 않고 한 번에 끝내는 방법

제품 촬영 후 파일명이 `IMG_4821.jpg`부터 `IMG_4920.jpg`까지 100장. 납품처 규격에 맞게 `product_001.jpg` 형태로 바꿔야 하는 상황. 탐색기에서 하나씩 F2 누르면 하루가 다 가겠더라고요.

## 왜 만들었나

파워쉘이나 터미널 명령어를 찾아보면 금방 해결되는데, 명령어가 익숙하지 않으면 틀릴까 봐 망설여지고, 잘못 실행하면 파일이 꼬일 수도 있어서 부담스럽죠.

그래서 파일 목록 올리면 바꾸기 전·후 이름을 미리보기로 보여주고, 확인 후 적용하거나 스크립트로 내보낼 수 있는 도구를 만들었습니다.

## 이 도구의 특징

- **파일이 서버로 전송되지 않음** — 이름만 처리, 파일 내용은 밖으로 나가지 않음
- **설치·로그인 없음** — 링크 열면 바로 사용
- **무료, 광고 없음**
- **변경 전·후 미리보기 + 스크립트 내보내기** — `.bat` / `.ps1` / `.sh` 로 저장해서 실행도 가능

## 주요 기능

- 규칙: **찾기·바꾸기**, **접두/접미사**, **연속 번호 매기기**, 대소문자, 공백 처리
- old→new **미리보기**로 안전 확인 후 적용
- 결과를 **새 이름 파일로 저장** 또는 **`.bat`/`.ps1`/`.sh` 스크립트로 내보내기**
- 원본은 그대로 — 항상 안전
- 사진·문서·로그 정리에 그대로 사용 [자세히](https://grit-tools.com/tools/file/batch-rename)

## 사용법

1. 이름 바꿀 파일 목록을 드래그하거나 클릭해서 불러오기
2. 변환 규칙 설정 — 찾기·바꾸기, 접두/접미사 추가, 연속 번호, 대소문자 변환, 공백 처리 중 선택
3. 미리보기에서 변경 전·후 파일명 확인
4. **파일로 저장** 또는 **스크립트 내보내기(.bat / .ps1 / .sh)** 선택 후 실행

## 활용 팁

**반드시 미리보기를 먼저 확인하세요.** 규칙이 의도대로 적용됐는지 한눈에 보이니까, 잘못된 패턴이 있으면 바로 수정할 수 있어요.

스크립트 내보내기가 유용한 상황도 있습니다. 같은 규칙을 매달 반복해야 한다면 `.bat`(윈도우) 또는 `.sh`(맥·리눅스) 파일로 저장해 두면 다음엔 스크립트 실행 하나로 끝납니다. **브라우저 도구는 파일을 직접 수정하지 않으므로 원본은 항상 안전**합니다.
