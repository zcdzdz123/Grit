# 우편번호 모를 때 신청서 막히는 거, 이제 여기서 바로 찾으세요

각종 신청서나 택배 송장 쓰다가 우편번호 칸에서 막힌 적 있으세요? 주소는 아는데 5자리 우편번호를 모르면 우체국 사이트 열고, 검색하고, 다시 신청서로 돌아오고… 이 흐름이 반복되면 생각보다 귀찮습니다. 특히 여러 건 처리할 때.

## 왜 만들었나

거래처 서류 작성하면서 주소 몇 개의 우편번호를 연속으로 찾아야 했어요. 탭 전환 반복하다가 그냥 도구 하나 따로 만드는 게 낫겠다 싶었습니다.

카카오(다음) 우편번호 서비스가 공개 API를 제공하고 있어서, 그걸 가져다 검색 인터페이스만 깔끔하게 만들었어요. API 키 발급이나 회원가입 없이 바로 씁니다.

## 이 도구의 특징

- **도로명·지번·건물명 모두 검색** — 아파트 이름이나 건물명으로도 찾을 수 있음
- **도로명 주소와 지번 주소 동시 확인** — 결과에서 두 형식 모두 표시
- **복사 버튼** — 우편번호, 도로명 주소, 지번 주소 각각 원클릭 복사
- **무료, 로그인 없음** — 카카오 우편번호 서비스 기반, API 키 불필요

## 주요 기능

- **도로명·지번·건물명** 어느 쪽으로도 검색 가능
- **5자리 우편번호 + 도로명·지번 주소** 동시 확인
- 검색 결과 클릭 한 번으로 복사
- 카카오(다음) 우편번호 서비스 기반 — **API 키·회원가입 불필요**
- 함께 쓰면 좋은 도구 → [한글 주소 영문 변환](https://grit-tools.com/tools/text/address-romanize)

## 사용법

1. 검색창에 주소 일부 입력 (도로명, 지번, 아파트·건물명 모두 가능)
2. 검색 결과에서 해당 주소 선택
3. 우편번호·도로명 주소·지번 주소 확인
4. 복사 버튼으로 필요한 항목만 바로 복사

## 활용 팁과 주의점

건물명으로 검색하면 해당 건물 주소가 바로 나와서 편합니다. "강남역", "코엑스", "롯데월드타워" 같이 쳐도 찾아줘요.

도로명 주소와 지번 주소 중 어느 것을 써야 하는지 헷갈릴 때는 공문서·공식 신청서는 도로명 주소를 쓰는 게 원칙입니다. 택배 송장은 둘 다 인식되니 편한 쪽으로 하면 됩니다. 영문 주소가 함께 필요하다면 [한글 주소 영문 변환 도구](https://grit-tools.com/tools/text/address-romanize)를 이어서 쓰면 됩니다.
