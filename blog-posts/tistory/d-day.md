# 시험·기념일 D-Day, 두 날짜 사이 일수까지 한 도구로 — 디데이 계산기

시험 날짜가 정해지면 제일 먼저 "지금부터 몇 일 남았지?"가 궁금해요. 달력 세어 보다가 틀리고, 검색하면 결과가 오늘이냐 내일이냐 기준이 제각각이라 찜찜하더라고요.

## 왜 만들었나

D-Day 앱은 많은데 대부분 스마트폰 전용이거나, PC에서 쓰려면 가입이 필요해요. 저는 그냥 브라우저 탭 하나에서 날짜 입력하고 바로 확인하고 싶었어요.

게다가 "두 날짜 사이 며칠?"이나 "오늘에서 100일 후 날짜는?"처럼 D-Day랑 자주 같이 쓰는 기능을 하나로 묶고 싶었고요.

## 이 도구의 특징

- **D-Day 카운트다운 + 경과일 동시 표시** — 목표일까지 남은 날, 이미 지난 날 모두 지원
- **두 날짜 차이 계산** — 시작일·종료일 넣으면 총 일수·주·월 단위로 출력
- **날짜 더하기·빼기** — 기준일에 N일을 더하거나 빼면 결과 날짜와 요일 표시
- **설치·로그인·광고 없음**

## 주요 기능

- **목표일까지 D-Day 자동 계산** — 남은 날과 이미 지난 날 모두 표시해요
- **두 날짜 사이 일수** — 정확한 총 일수와 요일까지 한 번에 확인
- **날짜 더하기·빼기** — 100일 후, 30일 전 같은 계산도 바로 가능
- **만 나이 응용** — 생년월일 넣으면 살아온 날 수로 만 나이 추정, [만 나이 계산하는 법](https://grit-tools.com/guide/korean-age)

## 사용법

1. 탭에서 원하는 기능 선택 (D-Day / 날짜 차이 / 날짜 계산)
2. 날짜 입력 (달력 팝업 또는 직접 입력)
3. 결과 — 남은 일수, 요일, 기념일 이름(옵션) 즉시 표시
4. 여러 날짜를 저장해두고 목록으로 관리 가능

## 활용 팁

**D-Day 당일은 D-0으로 표시됩니다.** 일부 사람들이 D-Day 당일을 D-1로 세는 방식을 쓰기도 하는데, 이 도구는 당일 = 0, 내일 = -1 방식이에요.

**만 나이 계산에도 응용할 수 있어요.** 2023년 6월부터 법적 만 나이 통일법이 시행됐는데, 생년월일을 시작일, 오늘을 종료일로 넣으면 살아온 날 수가 나와요. 거기서 365로 나누면 만 나이를 직접 확인할 수 있습니다.
