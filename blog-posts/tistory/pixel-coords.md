# HMI·임베디드 UI 좌표 따기, 파이썬 이미지 처리까지 — 클릭 한 번으로 픽셀 좌표 뽑기

HMI 화면 캡처 펼쳐 놓고 포토샵이나 GIMP로 좌표 확인하던 적 있으세요? 커서 위치 보면서 메모장에 숫자 옮겨 적고, 복붙하고, 또 다음 포인트 찍고… 포인트 수십 개면 그냥 노동이 되더라고요.

## 왜 만들었나

임베디드 UI 작업하면서 터치스크린 버튼 좌표를 `#define BTN_OK_X 312` 형태로 소스에 박아야 할 일이 생겼어요. 캡처 이미지를 열고 GIMP에서 픽셀 좌표를 읽어 손으로 타이핑했는데, 포인트가 20개 넘어가니까 실수가 나오기 시작했죠.

그래서 이미지 클릭 한 번에 좌표를 잡고, `#define` 형태나 함수 인자로 바로 복사할 수 있는 걸 만들었습니다. OpenCV 쪽 `cv2.rectangle()` 영역 지정할 때도 쓰더라고요.

## 이 도구의 특징

- **브라우저 안에서만 처리** — 이미지가 서버로 전송되지 않아요. 민감한 UI 캡처도 안심
- **설치·로그인 없음** — 링크 열면 바로 이미지 드롭
- **무료**
- **방향키로 1px 미세 조정** — 클릭으로 가까이 잡고 방향키로 정밀 보정 가능

## 주요 기능

- **이미지 클릭 → (x, y) 픽셀 좌표 추출** — 클릭한 지점의 좌표를 즉시 표시
- **방향키로 1px 단위 미세 조정** — 클릭으로 가까이 잡고 방향키로 정밀 보정
- **코드 포맷 자동 복사** — `#define`·함수 인자·좌표 쌍 등 원하는 형태로 바로 복사
- **여러 좌표 점 찍기·개별 삭제** — 포인트를 여러 개 찍고 필요한 것만 지울 수 있음
- **좌상단 기준 (0, 0)** — HMI·임베디드·OpenCV 등 대부분의 좌표계와 바로 호환

## 사용법

1. 이미지를 드래그 앤 드롭 (또는 클릭해서 파일 선택)
2. 이미지 위에서 원하는 지점을 클릭 → 우측에 `(x, y)` 표시
3. 1px 단위 조정이 필요하면 방향키로 이동
4. 출력 포맷(`#define`, 함수 인자, 좌표 쌍 등) 선택 → 복사 버튼

## 활용 팁과 주의점

좌표 기준점은 이미지 **좌상단이 (0, 0)**입니다. HMI·임베디드 프레임워크 대부분이 이 기준을 쓰지만, 간혹 좌하단 기준인 플랫폼도 있으니 소스 코드 확인 후 Y값을 뒤집어야 할 수도 있어요.

OpenCV에서 `cv2.rectangle(img, (x1, y1), (x2, y2), ...)` 식으로 영역 두 점이 필요할 때는 좌상단·우하단 두 번 클릭해서 각각 복사하면 편합니다. 게임 UI 버튼 위치 따거나, 자동화 스크립트에서 클릭 좌표 잡을 때도 쓸 수 있어요.
