# 알리·아마존 해외직구 영문 주소, 매번 헷갈리던 거 이제 붙여넣기로 끝냈습니다

알리익스프레스나 아마존에서 주문할 때 영문 주소 입력란이 뜨면 잠깐 멈추게 되죠. 서울특별시 마포구 어쩌고를 영어로 어떻게 쓰는 게 맞는 건지, Mapo-gu 인지 Mapo-Gu 인지, 띄어쓰기는 어떻게 하는 건지. 구글 번역기에 돌려도 뭔가 어색한 결과가 나오고, 결국 대충 쓰고 배송 올 때까지 조마조마했던 경험이 한 번쯤은 있을 겁니다.

## 왜 만들었나

직구 주문하면서 주소를 잘못 입력해서 배송이 지연된 적이 있었어요. 이후로 매번 국토교통부 영문 주소 가이드라인을 찾아보게 됐는데, 그 과정 자체가 번거로웠습니다.

국어의 로마자 표기법이 있고, 도로명 주소 영문 표기 규칙이 따로 있는데 일반 번역기는 이걸 구분하지 않아요. 주소는 고유명사 표기 규칙이 적용되는 특수한 텍스트라서, 표기법에 맞게 변환해 주는 도구가 필요했습니다.

## 이 도구의 특징

- **주소 표기법 기반 변환** — 구글 번역이 아닌 국어 로마자 표기법 + 도로명 주소 영문 표기 규칙 적용
- **도로명·지번 모두 지원** — 둘 다 넣으면 각각 영문으로 변환
- **브라우저 안에서만 처리** — 주소 정보가 서버로 전송되지 않음
- **설치·로그인 없음, 무료**

## 주요 기능

- 한글 주소 → **영문·로마자 주소** 변환
- **국어의 로마자 표기법 기반** — 구글 번역과 다른 표준 방식
- **도로명 주소·지번 주소** 모두 지원
- 모든 처리 브라우저 안 — 주소 정보 서버 전송 없음
- 해외직구 실전 케이스 → [해외직구 영문 주소 변환](https://grit-tools.com/guide/address-overseas)

## 사용법

1. 한글 주소를 입력창에 붙여넣기 (도로명 또는 지번 주소)
2. 변환 버튼 클릭 → 영문 주소 즉시 출력
3. 결과를 복사해서 직구 사이트 주소 입력란에 붙여넣기
4. 우편번호가 필요하면 [우편번호 검색 도구](https://grit-tools.com/tools/text/postal-code)에서 확인 후 함께 입력

## 활용 팁과 주의점

해외 직구 사이트는 대개 주소를 여러 줄 필드로 나눠 받습니다. Address Line 1에는 동/호수까지, Address Line 2에 건물명, City에 시, State/Province에 도, Postal Code에 5자리 우편번호를 넣는 방식이 일반적이에요.

구글 번역과 결과가 다를 수 있는데, 이 도구는 번역이 아니라 주소 표기 규칙을 적용한 변환이라 그렇습니다. 송장이나 공식 서류에 넣을 때도 이쪽이 더 안전합니다.
