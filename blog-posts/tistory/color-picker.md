# 포토샵 없이 스크린샷에서 색상값 뽑기 — 브라우저 스포이드 도구

디자이너한테 받은 시안에서 버튼 색상 HEX 값을 알아야 할 때, 예전엔 포토샵 열어서 스포이드 찍곤 했어요. 근데 포토샵이 없는 환경이거나, 그냥 스크린샷 한 장인데 앱을 켜기가 귀찮더라고요.

## 왜 만들었나

웹 작업하다 보면 레퍼런스 사이트 스크린샷에서 색상을 가져와야 할 때가 꽤 있어요. 브라우저 개발자 도구로 요소를 찾을 수 없는 경우 — 캡처 이미지, PDF 변환본, 앱 화면 캡처 등 — 에선 결국 이미지를 직접 픽셀 단위로 봐야 하죠.

OS 기본 스포이드 앱은 HEX는 주는데 HSL은 안 주거나, 반대로 클립보드 복사가 불편하거나 했어요. 클릭 한 번에 HEX·RGB·HSL 세 가지를 바로 복사할 수 있는 게 필요해서 만들었습니다.

## 이 도구의 특징

- **브라우저 안에서만 처리** — 이미지가 서버로 올라가지 않아요. 사내 디자인 시안이나 기밀 화면도 안심
- **설치·로그인 없음** — 링크 열고 이미지 드롭하면 끝
- **무료**
- **돋보기 미리보기 + 최근 색상 팔레트** — 정확히 어느 픽셀인지 확인하면서 선택 가능

## 주요 기능

- **HEX·RGB·HSL 세 포맷 동시 추출** — 이미지 클릭 한 번에 세 가지 색상값을 모두 확인
- **돋보기 루페** — 픽셀 단위로 정밀하게 위치를 확인하면서 색상 선택 가능
- **최근 색상 팔레트** — 여러 색을 한 번에 모아 비교하거나 나중에 참조할 수 있음
- **스크린샷·웹페이지 캡처에서도 그대로 사용** — 브라우저 개발자 도구로 접근할 수 없는 이미지에도 동작

## 사용법

1. 이미지를 드래그 앤 드롭 (또는 파일 선택)
2. 이미지 위에서 원하는 색상 위치를 클릭
3. HEX / RGB / HSL 중 필요한 포맷의 복사 버튼 클릭
4. 최근 선택한 색상은 하단 팔레트에 기록 — 여러 색 비교할 때 편해요

## 활용 팁

브랜드 컬러 정의할 때 로고 이미지를 불러와서 색상값을 직접 뽑으면 정확합니다. CSS `color` 속성에 쓸 땐 HEX, Figma나 Sketch에 넣을 땐 RGB가 편하더라고요.

한 가지 주의점은, **JPEG로 저장된 이미지는 압축 과정에서 색상이 약간 변할 수 있어요.** 원본 PNG나 디자인 파일에서 추출하는 게 가장 정확합니다. 혹시 "저 버튼이 정확히 무슨 색인지 모르겠다" 싶을 때는 PNG 스크린샷으로 찍어서 써보세요.
