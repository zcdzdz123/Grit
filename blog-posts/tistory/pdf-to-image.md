# PDF 페이지를 이미지로 캡처해야 할 때, 프린트스크린 없이 깔끔하게 변환하는 방법

PPT에 PDF 내용을 이미지로 넣거나, 카카오톡에 자료 일부를 그림으로 공유해야 할 때. 화면 캡처를 하면 해상도가 낮아서 흐릿하고, 어도비로 내보내자니 유료 기능이더라고요.

## 왜 만들었나

보고서 PDF를 팀장님한테 보여드리는데, 특정 페이지 두 장만 PPT 슬라이드에 이미지로 넣어야 했어요. 스크린샷은 화질이 별로고, 온라인 변환 사이트는 파일을 서버에 올려야 해서 망설여졌죠.

그냥 브라우저에서 바로 PDF 페이지를 PNG나 JPG로 뽑아낼 수 있으면 되겠다 싶어서 만들었습니다.

## 이 도구의 특징

- **파일이 서버로 전송되지 않음** — 로컬 브라우저에서만 처리
- **설치·로그인 없음** — 링크 열면 바로 사용
- **무료, 광고 없음**
- **PNG/JPG 선택 + 해상도 조절** — 용도에 맞게 화질과 용량 조절 가능

## 주요 기능

- 페이지별 **PNG 또는 JPG** 변환
- **해상도·품질 직접 지정** — 화질 vs 용량 조절
- 한 페이지씩 또는 전체 일괄 저장
- 페이지 선택 — 필요한 페이지만 골라서
- 모든 변환 브라우저 내, PDF 서버 전송 없음 [자세히](https://grit-tools.com/tools/pdf/pdf-to-image)

## 사용법

1. PDF 파일을 드래그하거나 클릭해서 불러오기
2. 변환할 페이지 선택 — 특정 페이지만 체크하거나 전체 일괄 선택
3. 형식(PNG/JPG)과 해상도 선택
4. **이미지로 저장** 클릭 → 페이지별 이미지 파일 다운로드

## 활용 팁

**화질 우선이면 PNG, 용량 우선이면 JPG**를 고르세요. PPT·문서 삽입용이면 PNG가 텍스트 선명도가 좋아요. 카카오톡 전송이나 웹에 올릴 거라면 JPG로 줄이는 편이 낫습니다.

해상도를 높이면 이미지가 더 또렷해지지만 파일 크기가 커요. 화면 표시 용도면 기본 해상도로 충분하고, 인쇄가 목적이면 해상도를 높여서 저장하세요.
