# 해외직구·여행 환율, 매번 검색하기 귀찮아서 만든 환율 계산기

아마존에서 물건값이 $79인데, 배송비랑 합산해서 원화로 얼마인지 계산할 때마다 구글에 "79달러 원화"를 치고 있더라고요. 여행 전날 밤엔 여러 통화를 왔다갔다 비교하다 탭이 열 개가 되기도 하고요.

## 왜 만들었나

환율 정보는 어디든 있는데, 정작 내가 원하는 건 딱 두 가지예요. "이 금액 환산하면 얼마야?"와 "반대로 얼마 환전하면 저 금액이야?" — 그 두 가지를 광고 없이, 로그인 없이, 깔끔하게 보여주는 도구가 없었어요.

그래서 ECB(유럽중앙은행) 기준 환율 API를 붙여서 직접 만들었습니다.

## 이 도구의 특징

- **실시간 환율 반영** — ECB 기준 환율 자동 적용 (frankfurter.app API)
- **양방향 전환** — 달러→원 뿐 아니라 원→달러도 바로 계산
- **개인정보·금액 데이터는 외부 전송 없음** — 통화 코드(예: USD, KRW)만 API에 요청
- **설치·로그인·광고 없음**

## 주요 기능

- **달러·유로·엔·원 등 주요 통화** — ECB 기준 실시간 환율 자동 반영
- **ECB 기준 환율(frankfurter.app)** — 매일 갱신되는 공신력 있는 환율 데이터
- **양방향 전환** — 보내는/받는 통화를 버튼 하나로 한 번에 스위치
- **통화 코드만 외부로 전송** — 금액·개인 정보는 브라우저 안에서만 처리해요

## 사용법

1. **기준 통화** 선택 (예: USD)
2. **변환 통화** 선택 (예: KRW)
3. **금액** 입력
4. 환산 결과 즉시 확인 — 반대 방향은 버튼 하나로 전환

## 활용 팁

**표시 환율과 실제 환전 금액은 달라요.** 은행·환전소는 여기서 보이는 기준환율에 스프레드(수수료)를 붙여서 고객 환율을 산출해요. 실제 환전 금액은 기준환율보다 1~2% 정도 더 나오는 경우가 많습니다. 이 계산기는 기준환율 기반이라 실제 환전 비용과 차이가 날 수 있다는 점 참고하세요.

**직구 총비용 계산에도 유용해요.** 상품가 + 배송비를 합산한 달러 금액을 입력하면 대략적인 원화 비용을 바로 잡을 수 있어요. 관세·부가세는 별도지만 1차 어림 계산엔 충분합니다.
