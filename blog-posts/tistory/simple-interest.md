# 예적금·차입 단리 이자, 매번 검색하기 귀찮을 때 쓰는 단리 계산기

원금 × 이율 × 기간. 공식은 간단한데 막상 손으로 계산하면 실수가 나더라고요. 특히 기간이 "1년 3개월"처럼 애매하면 더 헷갈리죠.

## 왜 만들었나

단기 예금 만기 이자를 확인하거나, 지인한테 돈을 빌려줄 때 이자를 어림잡아야 할 때가 종종 있어요. 계산기 앱을 켜서 직접 두드리자니 공식을 다시 찾아봐야 하고, 검색하면 광고 천지의 사이트가 뜨고요.

그냥 숫자 세 개 넣으면 이자, 세후 이자(이자 과세 15.4% 기준), 합계를 바로 보여주는 게 필요했어요. 만들고 나니 확실히 편하더라고요.

## 이 도구의 특징

- **계산 전 과정이 브라우저 안에서만** — 입력값이 밖으로 나가지 않아요
- **설치·로그인 없음** — 링크 열면 바로
- **무료, 광고 없음**
- **회차별 잔액 그래프 + 엑셀 다운로드** — 기간별 이자 추이도 한눈에

## 주요 기능

- **원금·이율·기간 입력** — 한 화면에서 이자·총액 즉시 확인해요
- **회차별 추이 그래프(SVG)** — 기간별 이자 증가 흐름을 한눈에
- **결과 엑셀(.xls) 저장** — 보관·공유에 바로 사용할 수 있어요
- **복리와 어떻게 다른지 궁금하다면** — [복리 vs 단리 차이](https://grit-tools.com/guide/compound-vs-simple)

## 사용법

1. **원금** 입력 (예: 500만 원)
2. **연 이율** 입력 (예: 4.0%)
3. **기간** 입력 (월 단위 또는 연 단위 선택)
4. 원금·이자·합계 결과와 그래프를 바로 확인 → 엑셀 저장 가능

## 활용 팁

**단리는 기간이 짧을수록 실용적입니다.** 단기 예금, 일수 이자, 개인 간 차용 계산에 많이 써요. 반면 장기 투자나 적금은 대부분 복리 구조라 같은 이율이라도 장기엔 복리가 유리해요.

**복리 계산기와 비교해보면 차이가 바로 보입니다.** 같은 조건으로 단리·복리 계산기를 각각 열어 비교하면 언제부터 차이가 벌어지는지 파악하기 좋아요. 5년 이내엔 생각보다 차이가 크지 않다는 것도 직접 보면 납득이 돼요.
