# 텍스트·로그 파일 여러 개, 터미널 없이 하나로 합치기

서버 로그 파일 일자별로 쌓인 거 한 번에 분석해야 하는데, 파일이 30개일 때 어떻게 하세요? 터미널에 익숙하면 `cat *.log > merged.log` 한 줄이지만, 그 환경이 없거나 Windows에서 작업 중이라면 얘기가 달라집니다. PowerShell 명령어 찾아보고, 인코딩 옵션 뭔지 검색하다 보면 합치는 것보다 방법 찾는 데 시간을 더 쓰게 되죠.

## 왜 만들었나

운영팀에서 로그 파일 취합 요청이 왔는데 담당자 PC가 Windows였고 터미널 환경이 없었어요. 파일 하나씩 열어서 복사하는 걸 반복하다가 순서도 뒤섞이고 결국 처음부터 다시 했습니다.

그냥 파일 드래그하면 순서 정해서 합쳐주는 게 있으면 되겠다 싶었고, 만들었습니다. .txt, .log, .md, .csv 어떤 텍스트 파일이든 됩니다.

## 이 도구의 특징

- **드래그 앤 드롭으로 파일 추가** — 여러 파일 한 번에 드롭, 순서는 드래그로 재정렬
- **구분자·파일명 헤더 옵션** — 파일 사이에 구분선 넣기, 파일명을 헤더로 삽입 선택 가능
- **UTF-8 BOM 옵션** — 엑셀에서 한글 깨짐 없이 열 수 있도록 BOM 포함 여부 선택
- **브라우저 안에서만 처리** — 파일 내용이 서버로 전송되지 않음, 설치·로그인 없음, 무료

## 주요 기능

- 여러 텍스트 파일을 **드래그&드롭으로 한 번에** 불러오기
- 지원 형식: `.txt`·`.md`·`.csv`·`.log`·`.json`
- 드래그로 **순서 정렬** — 결과 파일 순서를 직접 조정
- **구분자·파일명 헤더·UTF-8 BOM** 옵션 — 엑셀 한글 깨짐 방지에 BOM 유용
- 모든 처리 브라우저 안 — 파일 업로드 없음

## 사용법

1. 합칠 파일들을 드래그 앤 드롭으로 업로드
2. 파일 목록에서 순서를 드래그로 조정
3. 구분자, 파일명 헤더, BOM 옵션 선택
4. '합치기' 버튼 → 결과 파일 다운로드

## 활용 팁과 주의점

로그 파일을 날짜 순으로 합칠 때는 파일명에 날짜가 포함되어 있으면 업로드 후 이름순 정렬 버튼으로 한 번에 맞출 수 있어요.

UTF-8 BOM 옵션은 합친 파일을 엑셀에서 열 예정일 때 켜두세요. BOM 없는 UTF-8 파일은 엑셀에서 열면 한글이 깨지는데, 이 옵션을 켜면 엑셀이 인코딩을 자동으로 인식합니다. 텍스트 에디터나 터미널에서만 쓸 거라면 꺼도 됩니다.
