# 이직·연봉협상 때 실수령액 5초 만에 확인하는 연봉 실수령액 계산기

"연봉 4,500만 원 제시받았는데 실수령은 얼마야?" — 오퍼 레터 받는 순간 제일 먼저 드는 생각이죠. 세금 다 떼고 나면 생각보다 훨씬 적게 손에 쥐거든요.

## 왜 만들었나

연봉 협상 자리에서 "월 실수령 ○○만 원"을 바로 말하려면 계산이 필요한데, 검색하면 정보들이 제각각이에요. 어떤 사이트는 연도별 공제율이 안 맞고, 어떤 곳은 비과세 항목을 입력할 수가 없어서 항상 오차가 있더라고요.

4대보험(국민연금·건강보험·장기요양·고용보험)이랑 소득세·지방소득세까지 한 번에 계산해주는 도구를 직접 만들었습니다.

## 이 도구의 특징

- **연봉·비과세·부양가족·자녀 수 입력** → 공제 항목별 세액 + 월/연 실수령 출력
- **브라우저 안에서만 계산** — 급여 정보가 밖으로 나가지 않아요
- **설치·로그인·광고 없음**
- **공제 내역 항목별로 표시** — 어디서 얼마가 빠지는지 한눈에

## 주요 기능

- **연봉·비과세·부양가족·자녀 수 입력** — 공제 항목별 세액과 실수령액 한 번에 확인
- **4대보험·소득세·지방세 자동 공제 계산** — 어디서 얼마가 빠지는지 항목별로 표시해요
- **월·연 실수령액 추정** — 협상·이직 의사결정에 바로 참고 가능
- **연봉 5000 실수령액이 궁금하다면** — [연봉 5000 실수령액](https://grit-tools.com/guide/salary-5000)
- **연봉 7000 실수령액이 궁금하다면** — [연봉 7000 실수령액](https://grit-tools.com/guide/salary-7000)

## 사용법

1. **연봉 총액** 입력 (세전 연봉, 예: 4,500만 원)
2. **비과세 수당** 입력 (식대·교통비 등, 모르면 0)
3. **부양가족 수**·**자녀 수** 설정 (인적공제 반영)
4. 월 실수령·연 실수령·공제 내역 바로 확인

## 활용 팁

**비과세 항목이 실수령에 꽤 영향을 줍니다.** 식대 월 20만 원이 비과세로 잡히면 소득세 과세표준이 낮아져서 세금이 줄어요. 연봉 협상 시 비과세 항목을 늘리는 것도 실질적인 연봉 인상 효과가 있는 이유예요.

**어디까지나 추정치입니다.** 회사마다 적용 방식이 다를 수 있고, 연간 소득세 정산(연말정산)에 따라 실제 공제액은 달라져요. 이직 의사결정이나 협상 시 방향을 잡는 용도로 참고하는 게 맞아요. 정확한 공제액은 회사 급여 담당자나 세무사를 통해 확인하세요.
