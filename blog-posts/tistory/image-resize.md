# 카톡에 사진이 안 올라갈 때, 블로그 업로드가 너무 느릴 때 — 브라우저에서 바로 이미지 용량 줄이기

DSLR이나 최신 스마트폰으로 찍은 사진은 한 장에 5~10MB가 훌쩍 넘어요. 그런데 카카오톡이나 이메일로 보내려면 용량 제한에 걸리고, 블로그에 올리면 로딩이 느려지죠. 매번 그럴 때마다 앱 깔기도 귀찮고, 온라인 도구에 사진 올리기는 찜찜하고요.

## 왜 만들었나

블로그 글 쓸 때마다 사진 용량 때문에 한 번씩 막혔어요. 무료 온라인 압축 사이트는 쓸 때마다 사진이 서버로 올라가는 게 마음에 걸렸고, 로컬 앱은 실행 자체가 번거로웠죠. 그냥 브라우저 탭 하나 열고, 파일 드롭하면 결과 파일 받을 수 있으면 충분하다 싶어서 만들었습니다.

## 이 도구의 특징

- **사진이 서버로 전송되지 않아요** — 모든 압축이 브라우저 안에서만 처리. 개인 사진을 남의 서버에 올릴 필요 없음
- **설치·로그인 없음** — 링크 열면 바로 사용
- **무료**
- **가로 픽셀과 품질을 직접 지정** — 자동으로 줄여주는 게 아니라 원하는 크기로 정확하게 조정 가능

## 주요 기능

- **픽셀 또는 비율로 리사이즈** — 가로/세로 픽셀을 직접 입력하거나 비율로 조정
- **JPG 품질(압축률) 조정** — 화질과 용량 사이의 균형을 슬라이더로 직접 제어
- **형식 변환** — JPG ↔ PNG 전환 지원
- **100% 브라우저 처리** — 사진이 서버로 전송되지 않아 개인 사진도 안심
- **카톡·이메일 첨부 용도** — 권장 설정값 활용 ([카톡·이메일 첨부용 사진 용량 줄이기](https://grit-tools.com/guide/image-resize-kakao))

## 사용법

1. 이미지를 드래그 앤 드롭 (또는 파일 선택) — JPG, PNG 모두 지원
2. **가로 픽셀** 입력 (예: 1280 또는 1920)
3. **품질** 설정 (0~100, 기본 85 권장)
4. 다운로드 버튼 클릭 → 줄어든 파일 저장

## 활용 팁과 주의점

블로그 본문 이미지는 **가로 1280~1920px + 품질 80~85** 정도면 보통 1~2MB 안으로 들어와요. 카카오톡 전송이나 이메일 첨부 용도라면 가로 1080px + 품질 75로 더 줄여도 충분합니다.

JPG는 압축률이 좋은 대신 압축 흔적이 남을 수 있고, PNG는 투명 배경이 있는 이미지에 씁니다. 텍스트나 도형 위주 이미지는 PNG가 오히려 더 선명하게 나오기도 해요. 둘 다 같은 도구에서 지원하니 상황에 맞게 선택하면 됩니다.
