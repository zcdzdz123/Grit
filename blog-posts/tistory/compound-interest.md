# 내 적금이 복리면 얼마나 더 받을까? 5초 만에 비교하는 복리 계산기

은행 앱에서 적금 상품을 고를 때, "단리 3.5%"랑 "복리 3.2%"가 나란히 뜨면 어느 게 유리한지 순간적으로 헷갈리더라고요.

## 왜 만들었나

검색창에 "복리 계산기"를 치면 광고로 뒤덮인 페이지들이 뜨거나, 매번 로그인·회원가입을 요구하는 사이트가 걸렸어요. 그냥 원금, 이율, 기간 세 개만 넣으면 바로 답이 나오면 되는데 왜 이렇게 복잡한 걸까 싶었죠.

그래서 직접 만들었습니다. 숫자 넣으면 그래프가 바로 그려지고, 엑셀로도 저장할 수 있게요.

## 이 도구의 특징

- **브라우저 안에서만 계산** — 입력한 숫자는 서버로 전송되지 않아요
- **설치·로그인 없음** — 링크 열면 바로 씁니다
- **무료** — 광고도 없음
- **회차별 원리금 추이 그래프 + 엑셀 저장** — 기간이 길면 그래프가 얼마나 벌어지는지 눈으로 확인 가능

## 주요 기능

- **원금·이율·기간·복리주기 입력** — 한 화면에서 바로 결과 확인해요
- **회차별 추이 그래프(SVG)** — 시간 흐름에 따라 원금이 어떻게 불어나는지 시각화
- **결과 엑셀(.xls) 저장** — 보관·공유에 그대로 사용할 수 있어요
- **단리와 비교하고 싶다면** — [복리 vs 단리 차이](https://grit-tools.com/guide/compound-vs-simple)
- **원금이 두 배 되는 기간 추정** — [72 법칙 응용하기](https://grit-tools.com/guide/rule-of-72)

## 사용법

1. **원금** 입력 (예: 1,000만 원)
2. **연 이율** 입력 (예: 3.5%)
3. **기간**과 **복리 주기**(월/연) 선택
4. 바로 아래 그래프와 회차별 잔액 테이블을 확인 → 필요하면 엑셀 저장

## 활용 팁

**월복리 vs 연복리** 차이가 꽤 납니다. 연 3.5% 기준으로 10년을 맡기면 연복리보다 월복리가 눈에 띄게 더 불어나요. 은행 상품 안내서에 복리 주기가 적혀 있으니 꼭 확인하세요.

**장기일수록 복리 효과가 커집니다.** 5년 이내엔 단리·복리 차이가 크지 않아서 오히려 이율이 더 중요해요. 반대로 20년 이상이면 단리와 비교가 안 될 정도로 차이가 벌어지니 그래프로 직접 보는 게 직관적이에요.
