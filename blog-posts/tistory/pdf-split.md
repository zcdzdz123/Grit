# PDF 일부 페이지만 뽑아서 보내야 할 때, 서버 없이 브라우저에서 바로 나누는 PDF 분할 도구

계약서나 보고서 PDF가 30페이지인데, 상대방한테는 1~5페이지만 보내야 하는 상황. 전체를 그냥 보내자니 뒷내용이 신경 쓰이고, 어도비 편집 기능을 찾아보자니 유료라서 막히더라고요.

## 왜 만들었나

PDF 편집 도구들은 대부분 클라우드에 파일을 올려야 해요. 계약서·견적서·내부 자료처럼 외부로 나가면 곤란한 파일을 그렇게 올리기가 꺼려졌죠. 그렇다고 Adobe Acrobat 유료 플랜을 쓰기엔 단순 분할 하나 때문에 너무 과하고요.

그래서 파일이 서버로 한 글자도 나가지 않고, 브라우저 안에서만 처리되는 분할 도구를 만들었습니다.

## 이 도구의 특징

- **파일이 서버로 전송되지 않음** — 업로드 없이 브라우저 안에서만 처리
- **설치·로그인 없음** — 링크 열면 바로 사용
- **무료, 광고 없음**
- **낱장·범위·N장 단위 세 가지 방식** — 상황에 맞게 골라서 분할

## 주요 기능

- **낱장 분할** — 페이지마다 개별 PDF로 저장
- **페이지 범위 분할** — 예: 1~3, 5~7페이지만 따로 뽑기
- **N장 단위 분할** — 큰 PDF를 일정 페이지씩 자르기
- 결과 파일명 자동 생성 — 정리·구분 쉬움
- 모든 처리는 브라우저 안 — 파일 업로드 없음 [자세히](https://grit-tools.com/tools/pdf/pdf-split)

## 사용법

1. PDF 파일을 드래그하거나 클릭해서 불러오기
2. 분할 방식 선택 — 낱장(모든 페이지 개별 저장), 페이지 범위(예: 1-5), N장 단위(예: 5장씩)
3. 필요한 페이지 또는 범위 지정
4. **분할 저장** 클릭 → 결과 파일 다운로드

## 활용 팁

범위 분할을 쓸 때는 `1-3, 7, 10-12`처럼 쉼표로 여러 범위를 한 번에 지정할 수 있어요. 매번 한 범위씩 나눌 필요 없이 필요한 묶음을 한 번에 처리할 수 있습니다.

결과 파일명은 `원본파일명_p1-3.pdf`처럼 페이지 범위가 붙어 나와서 나중에 찾기도 편해요. 민감한 자료는 작업 후 브라우저 탭을 닫으면 메모리에서도 사라집니다.
