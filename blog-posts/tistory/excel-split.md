# 엑셀 시트별로 파일 나누기, VBA 매크로 없이 브라우저에서 끝내는 방법

월별 데이터를 시트로 나눠 관리하다가 팀원마다 담당 월만 따로 보내야 하는 상황. 매크로를 써야 하나 싶어서 찾아봤더니 VBA 코드가 줄줄이 나오고, 회사 PC는 매크로 실행이 막혀 있어서 결국 수작업으로 시트를 하나씩 복사해서 저장하고 있었어요.

## 왜 만들었나

워크북에 시트가 10개면 파일 10개를 만드는 게 단순 반복인데, 그게 생각보다 귀찮더라고요. 다른 이름으로 저장 → 불필요한 시트 삭제 → 저장. 이걸 열 번 반복하면 실수도 나고 시간도 낭비고요.

매크로를 쓰면 되는데 환경이 안 되는 경우가 많아서, 그냥 파일 올리면 시트 목록 보여주고 선택해서 저장하는 도구를 만들었습니다.

## 이 도구의 특징

- **파일이 서버로 전송되지 않음** — 브라우저 안에서만 처리
- **설치·로그인·매크로 없음** — 엑셀 매크로 실행 제한 환경에서도 동작
- **무료, 광고 없음**
- **XLSX 또는 CSV로 저장 선택** — 서식 유지가 필요하면 XLSX, 가볍게 쓸 거면 CSV

## 주요 기능

- 워크북의 **시트 목록 자동 인식**
- 시트 선택 — 전체 또는 일부만 골라서
- **개별 XLSX 또는 CSV로 저장**
- 매크로(VBA) 불필요 — 매크로가 차단된 환경에서도 가능
- 모든 처리 브라우저 안 — 민감 데이터 안전 [자세히](https://grit-tools.com/tools/file/excel-split)

## 사용법

1. 엑셀 파일(.xlsx)을 드래그하거나 클릭해서 불러오기
2. 시트 목록에서 분리할 시트 선택 (전체 또는 일부)
3. 저장 형식 선택 — XLSX(서식 유지) 또는 CSV(가볍고 범용)
4. **시트별로 저장** 클릭 → 각 시트가 개별 파일로 다운로드

## 활용 팁

**XLSX는 서식이 유지되지만 CSV는 셀 서식·수식이 사라집니다.** 지점별·부서별 자료를 그대로 넘겨줘야 하면 XLSX, 다른 시스템에 데이터만 넣어야 하면 CSV를 쓰세요.

매크로를 쓸 수 없는 환경(회사 보안 정책, 공용 PC 등)에서 특히 유용합니다. 원본 파일은 건드리지 않으니 실수로 덮어쓸 염려도 없어요.
