# 엑셀·노션 표를 GitHub README 마크다운 표로 — 복붙 한 방에 끝내기

GitHub README 쓰다가 표 때문에 막힌 적 있으세요? 노션에서 공들여 만든 표를 GitHub에 옮기려면 파이프(`|`)로 셀 하나하나 다시 쳐야 하고, 정렬이 조금만 틀려도 깨지고… 표 두 개만 넘어가면 이미 지쳐 있는 자신을 발견하게 됩니다.

## 왜 만들었나

프로젝트 문서 정리하면서 엑셀로 만들어 둔 API 파라미터 정리표를 README에 옮겨야 했어요. 열이 8개였는데 마크다운 문법 맞춰서 손으로 타이핑하다가 결국 틀렸고, 다시 세어 보다가 포기했습니다.

그래서 엑셀이나 구글시트에서 셀 범위 복사 → 그냥 붙여넣으면 마크다운 표 문법으로 변환해 주는 걸 만들었어요. 티스토리·velog에 코드 블록으로 붙여넣을 때도 똑같이 씁니다.

## 이 도구의 특징

- **탭·콤마 자동 인식** — 엑셀 복사(탭 구분)든 CSV(콤마 구분)든 구분자를 알아서 감지
- **정렬 지정 가능** — 열마다 좌/우/가운데 정렬 선택, GitHub·티스토리·velog 모두 적용됨
- **실시간 미리보기** — 변환 결과가 실제 표로 바로 렌더링되어 확인 가능
- **브라우저 안에서만 처리** — 데이터가 서버로 전송되지 않음, 설치·로그인 없음, 무료

## 주요 기능

- **엑셀·구글시트·노션 표** 자동 인식해 붙여넣기 한 번에 변환
- **CSV 텍스트**도 인식 — 탭·콤마 구분 자동 감지
- 결과는 **GitHub Flavored 마크다운 표**
- **미리보기 동시 표시** — 결과 모양 바로 확인
- 깃허브 README·블로그·노션에 그대로 복사

## 사용법

1. 엑셀·구글시트·노션에서 표 범위를 선택해서 복사 (`Ctrl+C`)
2. 입력창에 붙여넣기 (`Ctrl+V`) — 탭/콤마 자동 감지
3. 필요하면 열별 정렬(L / C / R) 지정
4. 변환된 마크다운을 복사 → README나 블로그에 바로 붙여넣기

## 활용 팁과 주의점

GitHub Flavored Markdown(GFM) 표 문법은 티스토리 마크다운 편집기, velog, Obsidian에서도 그대로 씁니다. 헤더 행이 없는 순수 데이터 표라면 첫 행을 헤더로 잡으니, 빈 헤더 행을 위에 하나 넣고 변환하면 깔끔하게 나와요.

CSV 파일(.csv)은 메모장으로 열어 전체 선택 → 복사 후 붙여넣으면 됩니다. 큰따옴표로 묶인 셀 안에 콤마가 있는 경우도 처리됩니다.
