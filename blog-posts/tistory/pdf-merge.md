# 스캔본 여러 장, 계약서에 첨부까지 한 파일로 묶기 — 브라우저에서 PDF 합치기

스캔본이 페이지마다 파일 하나씩 나오는 경우 있죠. 계약서 본문이랑 별첨 서류를 각각 받아서 하나로 합쳐서 보내야 할 때도 마찬가지고요. 어도비 애크로뱃은 유료고, 온라인 PDF 합치기 사이트는 문서를 서버에 올려야 한다는 게 계속 마음에 걸렸어요.

## 왜 만들었나

계약서나 신분증 스캔본처럼 민감한 문서를 외부 서버에 올리는 건 찜찜하잖아요. 그렇다고 유료 툴 구독하기엔 이걸 쓸 빈도가 그리 높지 않고요. 브라우저에서 파일을 읽고 합쳐서 바로 다운로드만 해주면 충분하다 싶어서 직접 만들었습니다.

## 이 도구의 특징

- **파일이 서버로 전송되지 않아요** — 계약서, 신분증 스캔본 등 민감한 PDF도 브라우저 안에서만 처리
- **설치·로그인 없음** — 링크 열면 바로 사용
- **무료**
- **드래그로 순서 정렬** — 파일 추가 후 원하는 순서로 끌어서 배치, 그대로 병합

## 주요 기능

- **드래그&드롭으로 여러 PDF 한 번에 불러오기** — 파일을 한꺼번에 끌어다 놓으면 목록에 추가
- **드래그로 순서 정렬** — 파일 목록에서 끌어서 배치, 그 순서가 곧 결과물의 페이지 순서
- **브라우저에서 병합·다운로드** — 파일 업로드 없이 처리, 계약서·스캔본도 외부 서버에 올라가지 않음
- **파일 개수·용량 제한 없음** — 브라우저 메모리 한도 내에서 제한 없이 사용 가능
- **스캔본 여러 장 묶기** — 페이지마다 파일이 따로 나온 스캔본을 한 PDF로 ([스캔본 여러 장 PDF로 합치는 법](https://grit-tools.com/guide/pdf-merge-scanned))

## 사용법

1. PDF 파일을 드래그 앤 드롭 (여러 개 한 번에 선택 가능)
2. 파일 목록에서 순서를 드래그로 조정
3. **PDF 합치기** 버튼 클릭
4. 완성된 파일 다운로드

## 활용 팁과 주의점

병합 전에 **파일 순서를 한 번 더 확인**하는 게 좋아요. 앞뒤가 바뀌면 다시 합쳐야 하니까요.

**암호가 걸린 PDF는 먼저 해제**해야 합칩니다. 암호 보호된 파일은 브라우저에서 내용을 읽을 수 없어서 병합이 안 돼요. 그리고 파일 용량이 크면(수십 MB 이상) 처리에 잠깐 시간이 걸릴 수 있어요 — 브라우저 탭을 그대로 두고 기다리면 됩니다.
