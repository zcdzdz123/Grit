우편번호 검색하는 방법 (도로명·지번 주소)

택배 보낼 주소를 입력하거나, 서류에 우편번호를 기재해야 할 때 주소에 맞는 5자리 우편번호를 빠르게 찾을 필요가 있습니다. 이 글에서는 회원가입·설치 없이 브라우저에서 도로명·지번 주소로 우편번호를 검색하고 복사하는 방법을 단계별로 정리합니다.

이런 분께 필요해요

  • 택배·우편 발송 시 수령인 주소의 우편번호를 확인해야 할 때
  • 온라인 쇼핑몰·공문서에 우편번호를 입력해야 할 때
  • 도로명 주소와 지번 주소를 함께 확인하고 싶을 때
  • 영문 주소가 필요한 국제 배송 시에도 활용할 수 있습니다

우편번호를 검색하는 단계

  1. 검색어 입력검색창에 동 이름, 도로명, 건물명, 지번 주소 일부를 입력합니다. 정확한 전체 주소가 아니어도 됩니다.
  2. 검색 실행검색 버튼을 누르거나 Enter 키를 누릅니다. 카카오(다음) 우편번호 서비스가 일치하는 주소 목록을 반환합니다.
  3. 주소 선택검색 결과 목록에서 찾는 주소를 선택합니다. 도로명과 지번 형식이 함께 표시됩니다.
  4. 우편번호·주소 복사5자리 우편번호와 도로명·지번 주소가 표시됩니다. 복사 버튼으로 원하는 형식을 클립보드에 바로 복사합니다.

5자리 우편번호란

2015년 8월, 도로명주소 전면 시행에 맞춰 기존 6자리 우편번호(구 우편번호)가 5자리 우편번호로 개편되었습니다. 현재 대한민국에서 공식적으로 사용하는 우편번호는 모두 5자리입니다. 택배사·공문서·온라인 쇼핑몰 주소 입력창도 5자리 우편번호를 기준으로 합니다.

도로명 주소와 지번 주소

같은 장소를 두 가지 방식으로 표기합니다.

  • 도로명 주소 — 도로 이름 + 건물 번호. 예: 테헤란로 152. 현재 공식 표기 방식.
  • 지번 주소 — 토지 지번 기준. 예: 역삼동 736. 옛 방식이지만 여전히 병행 사용.

두 방식 모두 같은 우편번호를 공유하므로 어떤 형식으로 검색해도 우편번호를 찾을 수 있습니다.

검색 팁

  • 전체 주소보다 동 이름이나 건물명만 입력하면 결과를 더 빠르게 좁힐 수 있습니다.
  • 아파트는 단지명(예: 래미안 퍼스티지)으로 검색하면 찾기 쉽습니다.
  • 건물명이 기억나지 않는 경우 도로명 + 번지 범위로 검색하세요.
  • 읍·면 지역은 면 이름 + 리 이름으로 검색합니다.

데이터 출처

카카오(구 다음) 우편번호 서비스 API를 사용합니다. 우정사업본부와 행정안전부 공식 주소 데이터를 기반으로 하며 주기적으로 업데이트됩니다. 별도 API 키 발급이나 회원가입 없이 사용할 수 있습니다.

자주 묻는 질문

5자리 우편번호란 무엇인가요?

2015년 8월 도로명주소 전면 시행에 맞춰 기존 6자리 우편번호가 5자리로 개편되었습니다. 현재 대한민국에서 사용하는 공식 우편번호는 5자리입니다.

도로명 주소와 지번 주소, 어떻게 다른가요?

도로명 주소는 도로 이름과 건물 번호로 표시(예: 강남대로 123), 지번 주소는 토지 지번 기준(예: 역삼동 123-4)으로 표시합니다. 둘 다 같은 우편번호를 공유합니다.

영문 주소가 필요하면 어떻게 하나요?

도구가 도로명 주소의 영문 표기를 함께 제공합니다. 국제 택배나 해외 서비스 가입 시 영문 주소란에 그대로 복사해 쓸 수 있습니다.

검색이 잘 안 될 때 어떻게 하나요?

전체 주소 대신 동 이름, 건물명, 도로명 일부만 입력하면 더 잘 찾을 수 있습니다. 아파트는 단지명으로, 일반 건물은 건물명이나 도로명 일부로 검색해 보세요.

주소 데이터 출처는 어디인가요?

카카오(구 다음) 우편번호 서비스 API를 사용합니다. 우정사업본부와 행정안전부 공식 주소 데이터를 기반으로 하며 주기적으로 업데이트됩니다.
