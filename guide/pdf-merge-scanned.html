스캔본 여러 장 PDF로 합치는 법 (설치 없이 브라우저에서)

복합기나 스캔 앱으로 문서를 스캔하면 페이지마다 파일이 따로따로 저장되는 경우가 많습니다. 계약서 3장, 영수증 5장, 신청서 2장이 각각의 PDF로 나뉘어 있으면 하나씩 첨부하거나 이메일로 보내기가 번거롭습니다. 이 글에서는 설치나 계정 없이 브라우저에서 바로 여러 PDF를 하나로 합치는 방법을 안내합니다.

이런 분께 필요해요

  • 복합기로 스캔했더니 페이지마다 파일이 따로 저장된 경우
  • 여러 사람에게 받은 서류를 한 PDF로 묶어 제출해야 할 때
  • 문서를 외부 변환 사이트에 올리기 꺼려질 때 — 모든 처리가 브라우저 안에서만 이뤄집니다

스캔본을 PDF로 합치는 단계

  1. 여러 PDF 불러오기합칠 파일들을 드래그&드롭하거나 선택해서 한 번에 불러옵니다. 파일 수 제한은 브라우저 메모리에 따라 다릅니다.
  2. 순서 드래그로 정렬목록에서 파일을 드래그해 원하는 순서로 조정합니다. 오름차순 자동 정렬 기능이 있다면 파일명을 001.pdf, 002.pdf 형식으로 맞춰두면 편합니다.
  3. 합치기 실행병합 버튼을 눌러 하나의 PDF로 합칩니다. 파일 크기에 따라 수초 안에 완료됩니다.
  4. 완성된 PDF 다운로드브라우저에서 파일을 직접 다운로드합니다. 서버 전송 없이 처리가 끝납니다.

순서·페이지 정리 팁

스캔 파일이 많을수록 순서 관리가 중요합니다.

  • 파일명 숫자 붙이기 — 스캔 단계에서 001_계약서1.pdf, 002_계약서2.pdf 식으로 이름을 맞춰두면 불러올 때 자동 정렬이 편합니다.
  • 회전이 필요한 페이지 — 옆으로 저장된 페이지는 병합 전에 PDF 뷰어나 편집기에서 먼저 회전해 저장하세요. 합친 뒤에는 수정이 번거롭습니다.
  • 미리보기 확인 — 병합 전 썸네일을 확인해 순서와 방향이 맞는지 체크합니다.

스캔본을 더 가볍게 만들려면

고해상도 스캔본은 한 장에도 수 MB가 넘는 경우가 있습니다. 파일이 너무 크면 이메일 첨부 한도를 초과하거나 업로드가 느릴 수 있습니다.

  • 스캔 해상도를 150~200 DPI로 설정하면 문서 가독성은 유지하면서 용량을 크게 줄일 수 있습니다.
  • JPG로 스캔했다면 이미지 용량 줄이기 가이드를 참고해 먼저 압축한 뒤 PDF로 변환하세요.
  • 이미 PDF라면 PDF 압축 도구로 전처리한 뒤 병합하면 최종 파일 크기가 줄어듭니다.

왜 브라우저에서 처리할까 — 보안

계약서·신분증·의료 서류처럼 민감한 문서가 스캔본에 담길 때가 많습니다. Grit의 PDF 병합 도구는 파일을 서버로 전송하지 않고 이용자의 브라우저 안에서만 처리합니다. 페이지를 닫으면 데이터가 남지 않습니다.

자주 묻는 질문

JPG로 스캔한 이미지도 이 도구로 합칠 수 있나요?

이 도구는 PDF 파일만 입력받습니다. JPG·PNG 이미지를 PDF로 합치려면 이미지→PDF 변환 도구를 먼저 사용한 뒤 병합하세요.

암호가 걸린 PDF도 합칠 수 있나요?

암호화된 PDF는 병합 전에 먼저 암호를 해제해야 합니다. 암호가 풀린 파일만 불러올 수 있습니다.

스캔본이 옆으로 돌아가 있으면 어떻게 하나요?

스캔 단계에서 방향을 맞춰 저장하거나, PDF 편집기로 회전을 먼저 처리한 뒤 병합을 진행하세요.

스캔본 용량이 너무 크면 어떻게 하나요?

스캔 해상도를 150~200 DPI로 낮추거나, 병합 전에 PDF 압축 도구로 각 파일을 먼저 줄이면 처리가 빠릅니다.

모바일에서도 사용할 수 있나요?

최신 모바일 브라우저에서도 동작합니다. 파일 정렬·관리가 편한 데스크톱 환경을 권장합니다.
