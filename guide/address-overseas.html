해외직구 영문 주소 변환 — 도로명·지번 한 번에

알리익스프레스·아마존·이베이 등 해외 쇼핑몰에서 결제할 때 영문 배송 주소를 요구합니다. 한국 주소를 영어로 바꾸는 규칙을 모르면 대충 구글 번역에 맡기기 쉬운데, 그러면 구조가 틀려 배송 오류로 이어질 수 있습니다. 이 글에서는 도로명·지번 주소를 국어의 로마자 표기법에 따라 정확하게 변환하는 방법과 배송 양식 작성 요령을 정리합니다.

이런 분께 필요해요

  • 알리·아마존·이베이 등 해외 쇼핑몰 배송 주소 입력이 처음인 경우
  • 도로명 주소와 지번 주소 중 무엇을 쓸지 헷갈릴 때
  • 아파트 동·호수 표기를 어떻게 해야 하는지 모를 때

단계로 변환하기

  1. 한글 주소 입력도로명 주소 또는 지번 주소를 입력합니다. 아파트 단지라면 동·호수까지 함께 입력하세요. 예: 서울특별시 강남구 테헤란로 123, 101동 202호
  2. 변환 실행변환 버튼을 누르면 국어의 로마자 표기법에 따라 영문 주소가 생성됩니다.
  3. 영문 주소 확인Address Line 1·2, City, Province, Postal Code 항목이 각각 어디에 해당하는지 확인합니다.
  4. 송장 양식에 복사·붙여넣기쇼핑몰 배송 주소 입력 화면에 붙여넣습니다. 고유명사나 건물명은 수동으로 검토하세요.

도로명 vs 지번 — 무엇이 좋은가

해외 배송에서는 도로명 주소를 우선 사용하는 것이 좋습니다. 도로명 주소는 한국 정부가 공식으로 영문화한 체계여서 우체국·배송사 시스템에서 인식률이 높습니다.

  • 도로명 주소 — 서울특별시 강남구 테헤란로 123 → 123 Teheran-ro, Gangnam-gu, Seoul
  • 지번 주소 — 서울특별시 강남구 역삼동 123-45 → 123-45 Yeoksam-dong, Gangnam-gu, Seoul

지번 주소도 배송이 가능하지만, 도로명이 있다면 도로명을 우선하세요.

우편번호도 같이 넣자

한국 우편번호는 5자리 숫자입니다. 배송 양식의 Postal Code 또는 ZIP Code 칸에 반드시 입력하세요. 우편번호를 빠뜨리면 현지 배송사에서 주소를 특정하지 못해 배송이 지연되거나 반송될 수 있습니다. 우편번호가 기억나지 않으면 우편번호 찾기 도구를 활용하세요.

자주 묻는 질문

도로명 주소와 지번 주소 둘 다 변환할 수 있나요?

네. 도로명·지번 주소 모두 영문으로 변환할 수 있습니다. 해외 배송에는 도로명 주소를 우선 사용하는 것이 일반적입니다.

아파트 동·호수는 어떻게 표기하나요?

동 번호는 'Dong', 호수는 'Ho'로 표기합니다. 예: 101동 202호 → 101-dong, 202-ho. 배송 양식의 Address Line 2에 입력합니다.

우편번호는 어떻게 넣나요?

한국 우편번호는 5자리 숫자입니다. 배송 양식의 Postal Code 또는 ZIP Code 칸에 입력하면 됩니다.

구글 번역과 어떻게 다른가요?

구글 번역은 한글을 직역해 주소 구조가 부정확할 수 있습니다. 이 도구는 국어의 로마자 표기법과 행정 체계 기준으로 변환해 배송 양식에 바로 쓸 수 있는 형태로 만들어 줍니다.

변환된 주소에 오타가 있으면 어떻게 하나요?

변환 결과는 직접 편집할 수 있습니다. 건물명·단지명 같은 고유명사는 수동으로 확인·수정하는 것이 좋습니다.
