엑셀 시트별로 파일 나누는 방법

하나의 엑셀 워크북에 시트가 여러 개일 때, 각 시트를 개별 파일로 분리해야 하는 경우가 많습니다. 부서·지점·월별로 나뉜 데이터를 따로 공유하거나, 시트마다 다른 사람에게 전달할 때죠. 시트를 하나씩 복사해 새 파일로 저장하는 수작업은 번거롭고 실수도 잦습니다. 이 글에서는 설치·로그인 없이 브라우저에서 엑셀을 시트별로 나누는 방법을 단계별로 정리합니다.

엑셀 시트별 나누기 도구브라우저에서 바로 실행 · 파일 업로드 없음

이런 분께 필요해요

  • 부서별·지점별로 나뉜 시트를 각각 파일로 보내야 할 때
  • 시트가 수십 개라 하나씩 복사·저장하기 비현실적일 때
  • 업무 데이터를 외부 변환 사이트에 올리기 부담스러울 때 — 브라우저 안에서만 처리되므로 안전합니다

엑셀을 시트별로 나누는 단계

  1. 엑셀 파일 열기분리할 .xlsx 또는 .xls 파일을 화면에 드래그&드롭하거나 선택해 불러옵니다.
  2. 시트 확인·선택워크북에 들어 있는 시트 목록이 표시됩니다. 분리하고 싶은 시트를 선택합니다(전체 선택도 가능).
  3. 저장 형식 선택서식을 유지하려면 XLSX, 가볍고 호환성이 좋은 CSV 중에서 고릅니다.
  4. 개별 파일로 저장각 시트가 별도 파일로 다운로드됩니다. 업로드 과정이 없으니 빠르고 안전합니다.

XLSX와 CSV, 무엇을 고를까

두 형식은 쓰임이 다릅니다. 상황에 맞게 고르세요.

  • XLSX — 서식·수식·여러 시트 구조를 그대로 유지. 다시 엑셀에서 편집할 때 적합.
  • CSV — 순수 텍스트라 가볍고, 다른 프로그램·DB로 가져오기 좋음. 단, 서식·수식은 빠집니다.

왜 브라우저에서 처리할까 — 보안

업무용 엑셀에는 매출·인사·고객 정보 같은 민감한 데이터가 들어 있는 경우가 많습니다. Grit의 도구는 파일을 서버로 보내지 않고 이용자의 브라우저 안에서만 읽고 나눕니다. 작업이 끝나고 페이지를 닫으면 데이터는 남지 않습니다.

자주 묻는 질문

엑셀 파일이 서버로 업로드되나요?

아니요. 파일을 읽고 시트를 나누는 모든 과정이 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.

시트가 수십 개여도 한 번에 나눌 수 있나요?

네. 브라우저 메모리 한도 안에서 여러 시트를 한 번에 개별 파일로 저장할 수 있습니다. 용량이 매우 크면 처리에 약간 시간이 걸릴 수 있습니다.

XLSX와 CSV 중 무엇으로 저장해야 하나요?

서식·수식을 유지하려면 XLSX, 호환성이나 가벼운 텍스트 데이터가 목적이면 CSV가 적합합니다.

설치나 회원가입이 필요한가요?

필요 없습니다. 페이지를 열면 바로 쓸 수 있고 무료입니다.

Mac이나 모바일에서도 되나요?

최신 크롬·엣지·사파리·파이어폭스 등 최신 브라우저라면 운영체제와 관계없이 동작합니다.

엑셀 시트를 개별 파일로 분리하기

  1. 매출·비용·요약 시트가 포함된 통합 문서를 불러옵니다.
  2. 시트 목록에서 이름과 행 수를 확인하고 필요한 시트만 체크합니다.
  3. 출력 형식을 정한 뒤 선택 시트 전체 다운로드로 개별 파일을 만듭니다.
