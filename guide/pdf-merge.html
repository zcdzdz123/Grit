PDF 합치기 — 여러 PDF를 하나로 합치는 방법

계약서·보고서·첨부 자료 등 여러 PDF 파일을 하나로 묶어야 할 때, 매번 별도 프로그램을 설치하거나 파일을 온라인 사이트에 올리는 건 번거럽습니다. 이 글에서는 설치·로그인 없이 브라우저에서 여러 PDF를 원하는 순서로 정렬해 하나의 파일로 병합하는 방법을 단계별로 정리합니다.

이런 분께 필요해요

  • 여러 장의 계약서·보고서·첨부 문서를 하나의 PDF로 묶어 전달해야 할 때
  • 스캔본 여러 개를 한 파일로 합쳐야 할 때
  • 순서를 바꾸거나 특정 파일만 골라 합쳐야 할 때
  • 업무 문서를 외부 사이트에 올리기 꺼려질 때 — 브라우저 안에서만 처리되므로 안전합니다

PDF를 하나로 합치는 단계

  1. PDF 파일 여러 개 불러오기합칠 .pdf 파일들을 화면에 드래그&드롭하거나, 파일 선택 버튼으로 한 번에 여러 파일을 불러옵니다.
  2. 드래그로 순서 변경파일 목록에서 각 항목을 드래그해 원하는 순서로 정렬합니다. 순서가 곧 병합 결과의 페이지 순서가 됩니다.
  3. 합치기 실행순서를 확인한 뒤 합치기 버튼을 누릅니다. 모든 처리는 브라우저 안에서 이뤄지며 서버로 전송되지 않습니다.
  4. 완성 파일 다운로드병합된 PDF 파일이 자동으로 다운로드됩니다. 파일명은 원하는 대로 변경할 수 있습니다.

PDF 합칠 때 주의할 점

병합 전 확인해두면 좋은 사항들입니다.

  • 파일 순서 확인 — 목록에 표시된 순서대로 페이지가 이어집니다. 합치기 전 순서를 꼭 확인하세요.
  • 암호 설정된 PDF — 열람 암호가 걸린 PDF는 먼저 암호를 해제한 뒤 불러오세요.
  • 파일 용량 — 이미지가 많거나 고해상도 PDF는 용량이 크므로 처리에 시간이 걸릴 수 있습니다.

왜 브라우저에서 처리할까 — 보안

계약서·법률 문서·개인정보가 담긴 PDF를 외부 서버에 올리는 건 보안상 위험할 수 있습니다. Grit의 PDF 합치기 도구는 파일을 서버로 보내지 않고 이용자의 브라우저 안에서만 읽고 병합합니다. 작업이 끝나고 페이지를 닫으면 데이터는 남지 않습니다.

자주 묻는 질문

PDF 파일이 서버로 업로드되나요?

아니요. 파일을 읽고 병합하는 모든 과정이 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.

합칠 PDF의 순서를 바꿀 수 있나요?

네. 파일 목록에서 각 항목을 드래그&드롭으로 원하는 순서로 정렬한 뒤 합칠 수 있습니다.

한 번에 합칠 수 있는 파일 개수 제한이 있나요?

별도의 파일 개수 제한은 없습니다. 다만 파일 용량 합계가 매우 크면 처리 시간이 길어질 수 있습니다.

파일 용량이 크면 어떻게 되나요?

용량이 클수록 처리 시간이 조금 더 걸릴 수 있습니다. 이미지가 많이 포함된 PDF는 특히 시간이 걸릴 수 있으니 잠시 기다려 주세요.

모바일에서도 사용할 수 있나요?

최신 크롬·사파리·엣지 등 최신 모바일 브라우저라면 운영체제와 관계없이 사용할 수 있습니다.
