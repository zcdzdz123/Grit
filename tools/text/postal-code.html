우편번호 검색

도로명·지번 주소를 검색해 5자리 우편번호를 바로 찾고 복사하세요.

주소 검색

주소 검색은 카카오(다음) 우편번호 서비스를 이용합니다.

검색 결과

주소를 검색하면 우편번호가 여기에 표시됩니다.

우편번호
도로명주소
지번주소

검색어와 선택한 주소는 조회를 위해 카카오(다음) 우편번호 서비스로 전송됩니다.

우편번호 검색 사용법

  1. 1검색창 열기

    왼쪽 검색창에 도로명 또는 지번 주소의 일부를 입력하세요. 예) 테헤란로 152, 또는 동·읍·면 이름.

  2. 2주소 선택

    검색 결과 목록에서 정확한 주소를 클릭하면 5자리 우편번호와 도로명·지번 주소가 오른쪽에 표시됩니다.

  3. 3우편번호 복사

    각 항목의 복사 버튼으로 우편번호나 주소를 클립보드에 담아 양식에 붙여넣으세요.
