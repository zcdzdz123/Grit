표를 마크다운으로 변환 사용법

  1. 1표 붙여넣기

    엑셀·구글 시트·노션에서 표 영역을 복사해 왼쪽 입력칸에 붙여넣으세요. CSV(쉼표) 텍스트도 됩니다.

  2. 2옵션 선택

    첫 줄을 헤더로 쓸지, 구분자(자동·탭·쉼표), 정렬(왼쪽·가운데·오른쪽)을 고르면 결과가 즉시 갱신됩니다.

  3. 3복사해서 사용

    ‘복사’를 누르면 GitHub 마크다운 표가 클립보드에 담깁니다. 셀 안의 | 는 자동으로 \| 로 처리됩니다.
