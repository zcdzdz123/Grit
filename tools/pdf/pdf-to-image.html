PDF는 서버로 전송되지 않습니다. 모든 변환은 이 브라우저 안에서만 처리됩니다.

페이지
PDF 파일을 불러오면 페이지 미리보기가 여기에 표시됩니다.

PDF를 이미지로 변환 사용법

  1. 1PDF 불러오기

    PDF 파일을 왼쪽 영역에 끌어다 놓거나 클릭해서 선택하세요. 페이지 미리보기가 바로 나타납니다.

  2. 2형식·해상도 선택

    출력 형식(PNG/JPEG), 해상도(1x~300 DPI), JPEG 품질을 고릅니다. 해상도가 높을수록 이미지가 선명하지만 용량이 커집니다.

  3. 3이미지 저장

    페이지마다 ‘이미지 저장’ 버튼으로 한 장씩, 또는 ‘모든 페이지 저장’으로 전체를 내려받습니다. 파일명은 원본이름_p01.png 형식입니다.
