# 원래 이름 새 이름

파일 이름 일괄 변경 사용법

  1. 1파일 또는 이름 불러오기

    파일을 끌어다 놓아 추가하거나, ‘이름만 직접 입력’ 탭에서 한 줄에 하나씩 이름을 붙여넣으세요. 파일은 브라우저 안에서만 처리되고 어디로도 업로드되지 않습니다.

  2. 2규칙 적용 · 미리보기

    찾기·바꾸기, 접두사·접미사, 연속 번호, 대소문자, 공백 처리를 위에서 아래 순서로 적용합니다. 오른쪽에서 원래 이름 → 새 이름을 바로 확인하고, 중복되는 이름은 경고색으로 표시됩니다.

  3. 3다운로드 또는 스크립트

    브라우저는 디스크의 파일을 직접 이름 바꿀 수 없습니다. 그래서 두 가지 방법이 있습니다. (1) 실제 파일을 불러왔다면 이름 바꿔 다운로드로 새 이름의 파일을 받습니다. (2) 스크립트 내보내기로 .bat·.ps1·.sh를 받아 폴더에서 실행하면 제자리에서 이름이 바뀝니다.
