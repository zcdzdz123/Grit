# Grit Tools

> 작은 반복을 갈아버리는 미니 도구 모음

설치 없이, 로그인 없이 브라우저에서 바로 쓰는 미니 도구 모음입니다.
모든 처리는 브라우저 안에서 이루어지며 파일·이미지·입력은 서버로 전송되지 않습니다.
**다크 모드 전용**, 풀스크린 레이아웃, 한국어·영어·일본어·중국어 4개 언어를 지원합니다.

## 구성

| 경로 | 설명 |
|------|------|
| `index.html` | 랜딩/허브 페이지 — 도구 카탈로그 |
| `i18n.js` | 다국어 엔진 (모든 페이지 공유) |
| `tools/` | 카테고리별 도구 (`image`, `text`, `calc`, `pdf`, `file`) |
| `TOOL-GUIDE.md` | 도구 제작 디자인 가이드 (새 도구는 이 문서를 따른다) |

## 실행

별도 빌드나 의존성이 없습니다. `index.html`을 브라우저에서 직접 열면 됩니다.

## 도구 목록 (16개)

### Image
- **이미지 좌표 추출기** — 이미지 클릭으로 픽셀 좌표 추출, 방향키 1px 조정, 코드 템플릿 복사
- **이미지 크기·용량 줄이기** — 브라우저에서 크기 조절·압축 후 다운로드 (업로드 없음)
- **이미지 색상 추출** — 스포이드로 픽셀 색을 찍어 HEX·RGB·HSL 복사, 확대 루페

### Text
- **표를 마크다운으로 변환** — 엑셀·구글 시트·노션 표/CSV → GitHub 마크다운 표 변환
- **한글 주소 영문 변환** — 한글 주소를 영문·로마자 주소로 변환 (국어의 로마자 표기법, 참고용)
- **텍스트 파일 합치기** — 여러 텍스트 파일을 순서대로 병합 (구분자·헤더·BOM 옵션)

### Calculator
- **복리 계산기** / **단리 계산기** — 그래프 + 엑셀 저장
- **연봉 실수령액 계산기** — 4대보험·소득세 차감 월/연 실수령액 추정 (2025년 기준)
- **디데이·날짜 계산기** — D-Day, 날짜 사이 일수, 날짜 더하기·빼기
- **환율 계산기** — ECB 기준 실시간 환율 변환

### PDF
- **PDF 나누기** — 낱장·범위·N장 단위 분할
- **PDF 합치기** — 여러 PDF를 원하는 순서로 병합
- **PDF를 이미지로 변환** — 각 페이지를 PNG·JPEG로 변환

### File
- **엑셀 시트별 나누기** — 워크북을 시트별 XLSX/CSV로 분리
- **파일 이름 일괄 변경** — 규칙 기반 이름 변경, 새 이름 다운로드 또는 .bat/.ps1/.sh 스크립트 내보내기

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크·빌드 도구 없음), ES5 호환
- 다국어 엔진은 자체 구현(`i18n.js`)
- PDF·엑셀 도구는 고정 버전 CDN 라이브러리(pdf-lib / pdf.js / SheetJS)를 사용하되, 파일은 브라우저에서만 처리(업로드 없음)
